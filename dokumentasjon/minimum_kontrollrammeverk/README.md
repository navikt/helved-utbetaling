# Minimum kontrollrammeverk for økonomisystem

Tema 2, 3 og 4 i _Minimum kontrollrammeverk for økonomisystem_ er i liten grad relevant for Team hel ved. Vi loggfører ikke kontroller på disse annet enn hva som kommer "ut av boksen" i _Mine tilganger_, _Nais_ o.l.

Nedenfor følger punktene som er særlig relevant og som jevnlig skal kontrolleres og følges opp av Team hel ved.

Se `.md`-fil per tema for detaljer om hvor og hvordan kontrollene loggføres.
